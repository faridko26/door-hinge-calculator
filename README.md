# Hinge Cup Location Calculator

A responsive web app that calculates European hinge cup locations for full-overlay cabinet doors.

## Features
- Calculate Door Height from Shelf openings.
- Calculate Top/Bottom Hinge Offsets based on Reveal (1/2", 1/8", 0").
- Calculate Intermediate Hinge Locations using 32mm system rules.
- Hinge quantity recommendations based on height.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open the URL shown in the terminal (usually http://localhost:5173).

## Build for Production

```bash
npm run build
```
The output will be in the `dist` folder.
